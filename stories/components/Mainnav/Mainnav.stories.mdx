# Mainnav

The SIT-branded main navigation bar. Composes this package's existing `Navbar`/`Navbar.Brand`/
`Navbar.Toggle`/`Navbar.Collapse`/`Nav` primitives (see `Components/Navigation/Navbar`) rather than
reimplementing them, and adds sit-mainnav's own slot API: `brand`, `end`, and `nonCollapsible`.
