# Split Button

`SplitButton` is a convenience component that renders a `Button` next to a `Dropdown.Toggle`, grouped together in a `ButtonGroup`. It is built for the common case of "a primary action, plus a menu of related actions".

The left-hand `Button` fires its own `onClick` (or acts as a link when `href` is set); the right-hand toggle opens a `Dropdown.Menu` built from the `children` you pass in, exactly like a regular `Dropdown`.

export const Template = (args) => (
  <SplitButton {...args}>
    <Dropdown.Item eventKey="1">Action</Dropdown.Item>
    <Dropdown.Item eventKey="2">Another action</Dropdown.Item>
    <Dropdown.Item eventKey="3">Something else</Dropdown.Item>
    <Dropdown.Divider />
    <Dropdown.Item eventKey="4">Separated link</Dropdown.Item>
  </SplitButton>
);

## Variants

`SplitButton` accepts the same `variant` values as `Button`, applied to both the action button and the toggle.

## As a link

Passing `href` (and optionally `target`) turns the action button into an anchor, while the toggle keeps opening the menu.

    </SplitButton>

## Accessibility

`id` is required on `SplitButton` — it is applied to the `Dropdown.Toggle` and is necessary for assistive technologies. The toggle also renders a visually-hidden label (`"Toggle dropdown"` by default) so screen reader users understand its purpose separately from the action button's `title`; override it with the `toggleLabel` prop when the default wording doesn't fit the context.
