# Checkbox

A dedicated, discoverable `Checkbox` -- fixes this repo's generic `FormCheck` to `type="checkbox"`,
the same "fix one prop" pattern `Form/Switch.tsx` already uses for `type="switch"`, rather than
reimplementing checkbox rendering.

<Canvas>
  <Story name="Basic">
    <Checkbox id="terms" label="I agree to the terms and conditions" />
  </Story>
</Canvas>

## API

```jsx
import { Checkbox } from '@sit-canvas/canvas-react/Checkbox';
```
