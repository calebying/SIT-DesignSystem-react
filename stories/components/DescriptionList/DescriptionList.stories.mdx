# DescriptionList

A label/data pair. The first child is the label, the rest is the data. Place one or more inside a
`<DescriptionList.Group>` for a titled group.

<Canvas>
  <Story name="Basic">
    <DescriptionList.Group title="Contact details">
      <DescriptionList>
        Name
        <span>Jane Tan</span>
      </DescriptionList>
      <DescriptionList>
        Email
        <span>jane.tan@example.com</span>
      </DescriptionList>
    </DescriptionList.Group>
  </Story>
</Canvas>
