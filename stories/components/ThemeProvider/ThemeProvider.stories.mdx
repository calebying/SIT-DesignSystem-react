# ThemeProvider

`ThemeProvider` is a React context provider used internally by every Canvas component (via the `useBootstrapPrefix` hook) to resolve each component's base CSS class prefix (e.g. `btn`, `card`, `popover`). Most consumers never need to render it directly — it exists so a custom-prefixed build of the library, or a consumer running a CSS class rename, can override the default prefixes for an entire subtree at once instead of passing `bsPrefix` to every component individually.

`ThemeProvider` also carries an optional `dir` value (e.g. `"rtl"`), read via the `useIsRTL` hook, which components like `Tooltip` and `Popover` use to mirror their positioning classes for right-to-left layouts.

export const Template = (args) => (
  <ThemeProvider {...args}>
    <Button>Prefixed Button</Button>
  </ThemeProvider>
);

## API
