# Icon

Renders a [bootstrap-icons](https://icons.getbootstrap.com/) glyph by name, at one of this design
system's usual size tiers.

export const Template = (args) => <Icon {...args} />;

<Canvas>
  <Story name="Basic" args={{ name: 'check-circle', size: 'lg' }}>
    {Template.bind({})}
  </Story>
</Canvas>

## Accessible label

An icon with no `ariaLabel` is decorative (`aria-hidden`). Set `ariaLabel` when the icon conveys
meaning on its own, with no adjacent text.

<Canvas>
  <Story name="Labelled">
    <Icon name="exclamation-triangle-fill" ariaLabel="Warning" className="text-warning" />
  </Story>
</Canvas>
