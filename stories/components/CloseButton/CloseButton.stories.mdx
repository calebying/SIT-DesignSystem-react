# Close Button

`CloseButton` is a generic dismiss icon-button, used by components like `Alert`, `Modal`, and `Toast` for their built-in dismiss controls, and available standalone for custom dismissible UI.

export const Template = (args) => <CloseButton {...args} />;

## Accessibility

`CloseButton` renders an `aria-label` of `"Close"` by default since it has no visible text — pass a more specific `aria-label` (e.g. `"Close alert"`) when the dismiss target isn't obvious from context alone.
