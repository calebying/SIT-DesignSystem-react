# Button Group

`ButtonGroup` groups a series of `Button`s together on a single line, sharing rounded corners at the group's edges instead of each button.

export const Template = (args) => (
  <ButtonGroup {...args}>
    <Button variant="secondary">Left</Button>
    <Button variant="secondary">Middle</Button>
    <Button variant="secondary">Right</Button>
  </ButtonGroup>
);

## API

```jsx

```

## Sizing

`size` applies to every `Button` in the group at once, so you don't need to size each individually.
