# Sidebar

A collapsible sidebar shell. Composes this package's existing `SideNav` primitive for its
navigation content (see `Components/SideNav`) and adds the outer chrome sit-sidebar has that
SideNav does not: collapse/scrim/variant behaviour and `upper`/`lower` header/footer slots.

**Known gap, not fixed in this pass:** the outer chrome classes this component adds
(`sidebar`, `sidebar-{variant}`, `sidebar-collapsed`, `sidebar-scrim`, `sidebar-upper`,
`sidebar-content`, `sidebar-lower`) don't have compiled CSS behind them in the current
`@sit-canvas/canvas-css` release yet -- only the Bootstrap utility classes alongside them
(`d-flex`, `flex-column`, `h-100`, `overflow-auto`) render visually today. The component's
structure and prop API are real and tested; the dedicated sidebar visual treatment is a real,
separate follow-up in the CSS package.
